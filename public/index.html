LLM 设置

纠错支持三档模式，各自独立配置（均为 OpenAI 兼容接口）。纯文本档还负责「整理重点」「AI 知识链」和复习页对话。密钥只保存在本机 config.json。

① 纯文本 最省 token

只发送 OCR 文字做纠错/总结。推荐 DeepSeek 等文本模型。

② 图片上云 精度最高

页面截图 + 文字一起发给云端视觉模型，按截图校对术语和公式。token 消耗约为纯文本的 5~10 倍。

③ 图片本地 零 API 费用

发给本机推理服务（Ollama / vLLM 跑 Qwen-VL 等）。你的 V100 16G 可跑 7B 量化模型。
