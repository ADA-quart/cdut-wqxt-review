使用说明

这个软件做的事：把问渠学堂的录播课件抓成本地图片 → 转成带公式的 Markdown → 在自己的复习台里对着课件复习、提问、做题、隔天自测。

第一次用，按这 4 步

  1. 登录：右上角点「登录」，输入统一认证学号密码。可能会自动弹出一个浏览器窗口让你过验证码，过完它会自己躲回屏幕外。
  2. 下载 PPT：左边选中课程 → 点「课次」挑一次课，或者直接点「下载」整门课。跑完在右下「已下载文件」里能看到课次目录。
  3. 转 MD：课次目录旁点「转 MD」，图片会被 OCR 成带公式的 Markdown，同时生成 PDF。（首次使用需要先装转换环境，见 README 的 setup 脚本；没装的话按钮会有提示。）
  4. 生成笔记 + 复习：进复习台先点「生成笔记」（AI 读原文整理出带 💭 讲解、习题折叠答案和课末必记的深度笔记）；左看笔记、右上翻课件、右下问 AI；⭐/❓ 标记不懂的页，第二天打开「复习」队列过一遍。

名词解释

词意思
课次一次课（如「2026-09-15第7-8节」）。下载、转 MD、复习都以课次为单位。「已下载文件」里一级是课程、二级是课次
转 MD把课件图片 OCR 成 Markdown，公式保留为 LaTeX，同时合成 PDF
去重清洗录播按帧抓图会有大量重复，自动去重（空白帧 / 等待页二维码 / 渐进重复），移除的帧进 _回收站/；复核页是全部帧的网格，勾选 = 清理、取消 = 保留，随时可拉回
知识链AI 在课次之间、课程之间建立双向链接（标准 [[...]]，可直接丢进 Obsidian）
图谱知识链的可视化（课程 / 课次 / 链接关系）
复习队列⭐ 重点、❓ 错题、✓ 掌握和 AI 出的问答卡，会按间隔重复排期提醒你复习

常见问题

  • 为什么下载时会有浏览器窗口？ 问渠学堂有动态防护，必须用真实浏览器内核；窗口默认在屏幕外，不打扰你。
  • 「转 MD」点不动？ 还没装转换环境 —— 在项目目录跑一次 setup-p2t.ps1（Windows）或 setup-p2t.sh（Mac）。
  • 文件存哪了？ 默认在项目下的 downloads/；可以在「设置 → 目录位置」改，笔记目录可以直接指向 Obsidian 库。
  • 这些下载合法吗？ 仅用于下载你本人账号有权访问的课件，请遵守学校相关规定。

设置

① 阅读舒适

主题四选一；护眼提醒按 20-20-20 法则（每 20 分钟看 6 米外 20 秒，美国眼科学会推荐）。深色适合低光环境；「护眼」是暖纸阅读色。

作用于笔记正文与对话；界面按钮不随动

② 目录位置

PPT 原始帧（图片）放在数据目录；Markdown / PDF / 公式图放在笔记目录。笔记目录可以直接指向 Obsidian 库，改完立即生效。

③ 转 MD 并行页数（单节内）

同一节课的 PPT 页之间并行转换（课与课之间仍串行）。默认「自动」：按当前空闲显存算能并行几页（实测模型基座约 6.2G、每多一页约 1G，并留 1.5G 余量）。版面分析会自动串行，保证结果和逐页转换完全一致。

④ 导出 / 导入

导出给手机 / 备份：内容包 = 笔记 + 课件图（给手机看）；学习记录包 = 进度 + 标记 + 对话（体积小，可两端来回合并）；全量备份 = 全部内容 + 记录。学习记录导入时永远按时间合并，不受下方「覆盖」开关影响。

⑤ 回收站

删除的课次先放到这里（按「课件与转换文件 / 学习记录」分类保存）。确认不再需要后可以彻底删除释放空间。

⑥ 升级 / 退出

升级走 git（需要是 git clone 安装的）；退出会关闭服务与后台浏览器进程。

登录验证码 / 需要手动操作时，唤出后台 Edge 窗口（平时藏在屏幕外）

删除课次

删除的内容会移到回收站，可在「设置 → 回收站」里恢复；确认不要了再彻底删除。

导入自定义课件

支持 PPT / PPTX（用本机 PowerPoint 导出每页图）、PDF（逐页渲染）、图片（可多选，按文件名顺序合成一节课）。导入后即可像问渠课件一样「转 MD → 生成笔记 → 复习」。
