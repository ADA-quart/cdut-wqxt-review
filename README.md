## 为什么有清渠

问渠学堂的录播是复习的主要资料，但用起来别扭：一节课摊开是上百张 PPT 截图，找某个公式要来回拖进度条；录播没有讲义，看第二遍还是从零开始。更麻烦的是那种「一整页就是一张图」的课件——老师讲了一节课，幻灯片上只有一张图，只看课件等于没看。

清渠把复习资料重做一遍：

- 课件逐页原图下载到本地，重复帧、等待页、二维码页自动清理；
- OCR 把每页转成带 LaTeX 公式的 Markdown，并合成可翻页的课件 PDF；
- 回放音轨本地转写成带时间戳的讲稿，**按页对齐后与课件一起交给模型**——老师口头强调的考点、易错提醒不再丢失；
- 生成**带页码引用的深度笔记**：要点旁标页号，点一下跳到课件对应页；难点配讲解，习题给「思路 / 计算 / 易错点」三段折叠答案，关键词条贴出关键图；
- 复习台把笔记、课件、AI 对话放在同一屏：划词提问、间隔重复自测、知识链串联课程。

整理好的内容可以导出到安卓 App 离线复习。所有数据都在自己的设备上，不经过任何服务器。

名字取自「问渠那得清如许」——把杂乱的课件，理成一渠清水。

## 它适合谁

- 成都理工大学在校生，有问渠学堂账号，想系统整理录播课件（其他学校需自行修改学校配置）；
- 翘了课要自学、期末要快速过课件的人：笔记里有课件内容，也有老师讲过而课件没写的内容；
- 习惯把资料收进 Obsidian / ima 的人——笔记是标准 Markdown，带课件 PDF 翻页链接与相对路径图片。

## 快速开始

> 前置条件：Node.js 18+；Windows 需安装 Microsoft Edge（登录用，脚本自动定位）。
> 两个可选的一次性环境：「转 MD」需要 Pix2Text 环境（约 6GB 模型）；「转写讲稿」需要 faster-whisper
> （首次自动下载约 1.6GB 识别模型）。两者都装好才能跑完整流水线，只装其一也能用对应功能。

桌面端四种启动方式（任选其一）：

| 方式 | Windows | macOS |
| --- | --- | --- |
| 网页版 | 双击 `start.cmd`（停止：`stop.cmd`） | 双击 `wqppt.command`（停止：`wqppt-stop.command`） |
| 桌面壳 | 双击 `启动复习软件.vbs` | 双击 `启动复习软件.command` |
| 命令行 | `npm install && npm start` → <http://127.0.0.1:3901> | 同左 |
| 升级 / 卸载 | `update.cmd` / `uninstall.cmd` | `bash wqppt.sh update` / `uninstall` |

> 桌面壳（Electron）首次安装要从 GitHub 下载约 100MB 运行库；国内网络失败时脚本会提示（Windows）或自动（macOS）用国内镜像修复。
> 手动修复：设 `ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'` 后 `npm install`；依赖已装仍缺运行库时执行 `npm rebuild electron`。

第一次使用走完一遍：

1. **登录**：右上角「登录」，输入统一认证账号；勾选「记住登录状态」后，会话过期会自动重新登录。动态防护需要真实浏览器会话，窗口默认在屏幕外，可在 设置 → 显示浏览器 唤出。
2. **下载**：勾选课程 →「下载所选」，或点「课次」只下某一次课；下载时顺带记录每页出现在录播的第几秒（讲稿对齐要用）。
3. **清洗**：课程「批量清洗」。复核页里勾选＝清理、取消＝保留；被清理的帧进 `_回收站`，随时可恢复。
4. **转 MD**：课程「批量转 MD」。图片 → 带公式的 Markdown + 课件 PDF（需先装转换环境）；**完成后自动校订**。
5. **讲稿（可选，推荐）**：课次旁「转写讲稿」——抓回放音轨后本地识别，90 分钟的课约 6 分钟。
6. **生成笔记**：默认走**视觉链路**（看图 + 讲稿），生成后**自动复核**，复核完再自动补全缺失知识点。
7. **复习**：进入复习台，按「复习」队列做间隔重复自测。

也可以完全不动脑：顶部「一键处理」按 **今天 / 本周 / 本月** 一键下载课件、一键跑完整笔记流程、一键导出内容包。

### 安装转换环境（转 MD 用，一次性）

```powershell
# Windows（需 uv + Python 3.12；有 N 卡自动走 CUDA，否则 CPU）
powershell -ExecutionPolicy Bypass -File setup-p2t.ps1
```

```bash
# macOS / Linux（Apple 芯片自动走 MPS）
bash setup-p2t.sh
```

> 国内网络连不上 `download.pytorch.org` 时，先用镜像再执行：
> Windows 设 `$env:PYTORCH_INDEX='https://mirror.nju.edu.cn/pytorch/whl/cu124'`；
> macOS / Linux 用 `PYTORCH_INDEX=https://mirror.nju.edu.cn/pytorch/whl/cu124 bash setup-p2t.sh`（上海交大镜像同理，把域名换成 `mirror.sjtu.edu.cn/pytorch-wheels/cu124`）。

装好后课次旁才会出现可用的「转 MD」。也可以命令行直接转：

```bash
.venv-p2t/Scripts/python.exe ppt2md.py "downloads/课程/课次" --device auto   # Windows
.venv-p2t/bin/python     ppt2md.py "downloads/课程/课次" --device auto       # macOS / Linux
```

### 安装转写环境（转写讲稿用，一次性）

讲稿需要两样东西：**ffmpeg**（抽音轨）和 **faster-whisper**（语音识别）。ffmpeg 是命令行工具，
faster-whisper 是 Python 包，都与 OCR 环境相互独立：

```bash
winget install Gyan.FFmpeg          # Windows 装 ffmpeg（macOS：brew install ffmpeg）
pip install faster-whisper          # 用哪个 Python 装，清渠就用哪个跑（自动探测）
```

界面里点「转写讲稿」前会自检这两样，缺哪个会直接提示装什么（`GET /api/replay-tools` 可查状态）。
**想确认「模型下没下」**：打开任意课程的「课次」弹窗，底部那行会写明
`ffmpeg ✓ ｜ faster-whisper ✓ ｜ 识别模型 ✓ large-v3-turbo（1543 MB）｜ 已抓音轨 N 节 / M MB`；
也可以用 `GET /api/replay-tools` 查（返回模型是否就绪、体积、目录，以及已抓音轨的节数与占用）。
首次转写会自动从 HF 镜像下载 `large-v3-turbo` 模型（约 1.6GB）到 `run/asr/` 之后复用；
CUDA 可用走 GPU（V100 实测约 26 倍速），否则回落 CPU；多个 Python 环境时用 `QINGQU_ASR_PYTHON` 指定解释器。

```bash
python transcribe.py "downloads/音频/课次.m4a" -o "笔记/课程/课次.trans.json" --model large-v3-turbo
```

## 📱 安卓 App

桌面端负责重活，App 负责随身复习。安装：[Releases](https://github.com/ADA-quart/cdut-wqxt-review/releases/latest) 下载 `qingqu-x.y.z.apk`；CI 自动构建、固定签名，新版本可直接覆盖安装。

App 内置更新检查：启动时静默查询 GitHub Releases，发现新版本时首页顶部横幅提示；页脚「检查更新」也可手动检查，点「下载更新」在 App 内直接下载并自动弹出系统安装器（首次需允许「清渠」安装未知应用），本地数据不丢。

**使用流程**

1. 电脑端「设置 → 导出」导出「内容包」（笔记 + 课件图；首次全量，之后可按课程 / 单课增量导出）；
2. 可选再导一个「学习记录包」（进度 + 标记 + 对话，几百 KB）；
3. 把 zip 传到平板 / 手机，App 内点「＋ 导入内容包」；
4. 之后完全离线使用。

**App 能做到**

- 笔记阅读（公式渲染、目录、页码角标、知识链）、课件翻页；
- 阅读进度自动记录，⭐ 重点 / ❓ 错题 / ✓ 掌握，复习队列（间隔重复），历史对话；
- 主题（跟随系统 / 浅色 / 深色 / 护眼暖纸）、正文字号四档、20-20-20 护眼提醒；
- 手机 / 平板的横屏竖屏均可：手机竖屏单列（笔记 → 课件 → 对话）、宽屏两栏。

**边界**：下载、转 MD、转写讲稿、生成笔记、校订只在电脑端，App 内自动隐藏；内容存 App 私有存储，卸载即清；导入后的压缩包可以删除。

## 功能说明

以下按流水线顺序说明各环节，供使用时查阅。

### 下载（问渠学堂）

- 登录走学校统一认证，后台是独立 profile 的真实浏览器会话（动态防护必须如此）；
- 课程按学期筛选，可整课下载；课次弹窗里可预览图片、单独下载；
- 下载时把每页出现在录播的第几秒记进 `<课次>.pages.json`（讲稿按页对齐的依据）；旧课件缺失时会在生成笔记时按标题反查补齐；
- 课次弹窗里的「**同时抓音轨**」（默认关，勾选会记住）：下载时顺手抓回放音轨（只抓不转写，约 45MB/节）——「下载所选」和「一键下载」都沿用它；
- **强制重新下载**（课件在服务器更新后用）：已有图片覆盖更新，已清洗的帧不拉回，服务器已删除的旧帧移入 `_回收站/_旧帧备份/`；
- 已存在且正常的图片自动跳过，重复下载幂等。

### 导入自定义课件

老师发的、自己找的课件也能进同一套流水线（转 MD → 清洗 → 生成笔记 → 复习）：已下载文件面板右上「＋ 导入课件」。

- **PPT / PPTX**：调用本机 PowerPoint 静默导出每页图；
- **PDF**：逐页渲染，可选 160 / 220 dpi（扫描件、图片拼合的 PDF 选高清）；
- **图片**：多选，按文件名顺序合成一节课。

### 清洗（去重）

- 规则：空白过渡帧丢弃；连续重复簇保留末帧；等待页与二维码页整段移除；
- 复核页把全部帧网格平铺：勾选＝清理（红框标出）、取消＝保留；勾选名单跨次沿用；
- 原始图片不删除，清洗只决定「转 MD 用哪些帧」；被清理的帧进 `_回收站`，随时拉回；
- 转 MD 默认先自动清洗一遍（可在「已下载文件」工具栏取消「转 MD 前先自动去重」）；在复核页改过决定后，需「重新转 MD」才会应用到原文 md 与笔记。

### 转 MD（课件数字化）

- Pix2Text 逐页 OCR 成 Markdown，公式保留 LaTeX；图形素材进 `<课次>_assets/`；
- 同时合成课件 PDF（图片合订），每页顶部带 `[[课次.pdf#page=N]]` 翻页链接，方便 Obsidian / ima 对照；
- 并行度按空闲显存与 CPU 核数自适应（V100 实测：模型基座 + 首页约 6.3GB，每多并行一页 +1GB，默认留 1.5GB 余量）。

### 讲稿（回放转写）

课件是一张图、老师却讲了一节课的课，靠 OCR 拿不到内容——用回放音轨补上：

- 课次旁的「转写讲稿」：抓这节课的回放音轨（视频只作中转，抽完即删），本地跑语音识别；
- 产出 `<课次>.trans.md`（带时间戳的讲稿）与 `<课次>.trans.json`（分段时间轴）；
- 模型 faster-whisper `large-v3-turbo`，CUDA 可用时走 GPU；V100 实测 91 分钟课次约 6 分钟（含抓流与抽音轨）；
- 音轨存 `<数据目录>/audio/<课程>/`（约 45MB/节），已存在时重跑跳过抓流，换模型或重试不用再下一遍；
- 生成笔记时**按页对齐**：某页讲解 = 从该页出现，到下一张保留页出现为止的讲稿片段（清洗删帧也不会错位）。

平台自带「语音识别」不可依赖：2026-10-09 抽样 144 个课次只有 74% 有结果，当学期新录课次仅 14%，所以讲稿一律本地生成。

### 校订（纠错 + 修公式）

- 一步跑完：OCR 错字逐页修正 → KaTeX 无法解析的公式按上下文修复，复验通过才写回；
- **转 MD 完成后自动执行**，无需手动触发；要重跑，进复习页「⋯ 更多 → 重新校订」；
- 备份 `.ocr-backup.md` / `.math-backup.md`；
- 三种模式：纯文本（省 token）/ 图片上云（视觉模型核对，精度最高）/ 图片本地（Ollama 等本机推理，零 API 费用）。

### 深度笔记（核心）

产出 `<课次>.note.md`。**默认走视觉链路**：把每页幻灯片截图与「老师当时讲了什么」交给能读图的模型，先逐页整理、再按知识逻辑重组成稿。
同课次实测（含自动复核与知识点补全）：比文本链路省 34% 输入、44% 输出、约 45% 时间，质量指标持平（详见[技术笔记](docs/technical-notes.md)）。

链路由程序自动选择：有能读图的档位走视觉，没有就回落文本链路（OCR 原文 → 整理稿 → 成稿），
不在界面上给选择项；「LLM 设置」里那行提示会显示当前哪些档位能读图、实际走哪条链路。
要强制走文本链路（排查用），改 `config.json` 的 `llm.notePipeline`，或调 `PUT /api/llm-config`。

**生成笔记前会自动补讲稿**：该课次有回放、但还没有讲稿时，先抓音轨并转写，再生成笔记——
三个入口（课次「生成笔记」、课程行「批量生成笔记」、一键笔记）行为一致。
未登录或无回放时会跳过并写进任务日志，不阻断笔记（开关：`config.json` 的 `automation.transcribeBeforeNote`）。
注意**「转 MD」与讲稿无关**：它只把图片 OCR 成原文并合成 PDF。

笔记固定结构：最前是 **📌 事务通知**（考试时间 / 地点 / 题型 / 范围、作业截止，来自课件或老师口头，没有就整块不出现）与 **🧭 本课脉络**；
接着是**知识小节**（按知识逻辑重组、要点带可点击页码角标、需要理解处写「💭 讲解」，
每道习题配折叠答案——思路 / 计算 / 易错点三段，关键图贴在被讲的那一节，整页是图的课次贴整页原图）；
**课程内容之后**才是 **🎯 课末必记**，再往后是自动生成的小节（📌 补充要点 / 📎 关键图 / 📌 知识点补全）。

覆盖保证：每页至少被引用一次，未覆盖的页会拿图再补一次；模型漏贴图时自动附上关键图。

**笔记 PDF**：复习页「⋯ 更多 → 笔记 PDF」，无头 Edge 渲染 A4（公式渲染、习题全部展开），按 mtime 缓存秒开。

### 质量审计与知识点补全

三层检查：页覆盖（本地，不花钱）+ 忠实度逐条核对（LLM）+ 知识点清单（LLM）。发现与原文不符处自动修正（AI 自己的补充内容保留），改前备份 `.note-backup.md`，面板可对照修正前后。

核对依据是**课件原文 + 该页老师讲解**（有讲稿时）：老师口头讲的内容同样算「有依据」，不会因为课件上没写而被当成幻觉删掉；条目引用多页时按全部引用页核对，知识点清单也读讲稿。

审计后还有一步**知识点补全**：清单里标了缺失 / 不完整的考点，会自动拿对应页的课件原文与讲解补写要点并追加到笔记末尾（带页码角标），补完再核对一次状态。实测一节课从「44 覆盖 / 10 不完整 / 3 缺失」补到 **57/57 全覆盖**。

**生成笔记后自动执行**；要重跑，进复习页「⋯ 更多 → 重新复核」。

### 一键批处理（今天 / 本周 / 本月）

顶部「一键处理」三个菜单，跨全部课程按课次日期处理：

- **下载课件**：把该周期内所有课次（跳过已下架课程）加入下载队列；
- **一键笔记**：对该周期内已下载的课次跑完整流水线——转 MD → 校订 → 生成笔记 → 复核；已有且未过期的笔记自动跳过；
- **一键导出**：把该周期的笔记 + 课件图打包成「内容包」，直接传到手机 / 平板。

### 复习台

- **布局**：左笔记（可切原文 md）、右上课件、右下 AI 对话；分隔条可拖动，布局按课次记忆；
- **笔记**：目录与小节折叠、四色荧光笔（核心考点 / 要背 / 已掌握 / 存疑）、页码角标点击跳课件；
- **课件**：翻页、缩略图、跟随滚动、键盘 ←→；⭐ 重点 / ❓ 错题 / ✓ 掌握 一键入队；🧠 出题生成问答卡；
- **AI 对话**：范围可选本课 / 本课程 / 全库（检索后回答并附来源）；划词「引用到提问 / 解释这段」；历史按课次保存；
- **复习队列**：间隔重复四档评分（再来一次 / 有点难 / 记住了 / 太简单）；费曼复述（AI 找缺漏）；导出 Markdown / CSV；
- **知识链**：课程内索引、课程间关联、反链、标签、图谱；
- **阅读舒适**：主题（跟随系统 / 浅色 / 深色 / 护眼暖纸）、正文字号四档、可选 20-20-20 护眼提醒。

### 导出 / 导入（与手机同步）

| 包 | 内容 | 用途 |
| --- | --- | --- |
| **内容包** | 笔记 + 原文 + 课件图 | 手机 / 平板；范围可选 全部 / 按课程 / 单课 |
| **学习记录包** | 阅读进度 + 复习卡 + 对话历史 | 双端来回合并 |
| **全量备份** | 全部内容 + 记录 | 备份 / 换机 |

- 包内带每课次**内容指纹**，App 端据此增量合并（新增 / 更新 / 跳过）；导入时学习记录永远按时间合并（进度取新、卡片按 id、对话并集去重），内容文件默认跳过、可勾选覆盖。

### 删除与回收站

课次可单选或批量多选删除。删除＝移入回收站，弹窗分两档勾选：课件与转换文件 / 学习记录（整理稿、对话、卡片**默认保留**）。设置 →「回收站」可恢复（原路返回）、彻底删除或一键清空。

## 数据与隐私

- 全部数据在本地：课件图、md、笔记、讲稿、声轨、卡片、对话都在你的电脑上（默认 `downloads/`，可改；笔记目录可直接指向 Obsidian 库）；安卓 App 同理，内容存 App 私有存储；
- 没有账号系统、没有遥测、没有中转服务器。LLM 调用从本机直接发往你配置的服务商（OpenAI 兼容接口），key 存本地 `config.json`（已 gitignore）；
- 视觉链路会把幻灯片截图随笔记生成发给模型，其余处理（转写、OCR、清洗）都在本机完成。

## 常见问题

- **没有转换环境能做什么？** 登录、下载、清洗、转写讲稿、导入现成 md 都能用；只有「转 MD」需要一次性安装（约 6GB 模型）。
- **转写讲稿报缺依赖？** 需要 `ffmpeg`（`winget install Gyan.FFmpeg`）和 `faster-whisper`（`pip install faster-whisper`）；
  机器上有多个 Python 时用 `QINGQU_ASR_PYTHON` 指定解释器。首次转写还会自动下 1.6GB 识别模型到 `run/asr/`，
  网络不好可以从别的机器直接把整个 `run/asr/` 目录拷过来（模型与机器无关）。
- **笔记会走哪条链路？** 默认自动：有能读图的档位就走视觉（省 token、快），否则回落文本。可在「LLM 设置 → 笔记生成方式」固定，旁边那行会显示实际结果。
- **为什么必须弹浏览器？** 问渠学堂登录与页面有动态防护（瑞数式 WAF），普通 HTTP 请求会被拦截；图片服务器无防护，可直下。
- **端口冲突？** 默认 3901，`PORT=xxxx npm start` 更换。
- **课件更新了怎么办？** 课次弹窗勾选「强制重新下载」→「重新转 MD」→「生成笔记」（缓存按 mtime 自动失效）。
- **数据会被改乱吗？** 原始 md 只在「校订 / 摘要块」两处写入且都有备份；笔记、审计、卡片、对话全部独立存储。
- **App 怎么更新 / 内容怎么同步？** App 页脚「检查更新」→ 有新版本时点「下载更新」，App 内下载完自动弹出安装器覆盖安装（首次需允许「清渠」安装未知应用；内容在 App 私有存储，覆盖安装不丢）；内容同步：电脑重新导出后 App 导入，同一课次自动替换。
- **导入的 zip 能删吗？** 能，导入完成即入库，压缩包不再需要。

## 开发与构建

```bash
npm test            # JS 语法自检（tools/check-syntax.mjs）
```
