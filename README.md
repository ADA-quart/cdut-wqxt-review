## 为什么有清渠

问渠学堂的录播是复习的主要资料，但用起来别扭：一节课摊开是上百张 PPT 截图，找某个公式要来回拖进度条；录播没有讲义，看第二遍还是从零开始。

清渠把复习资料重新做了一遍：

- 课件每一页原图下载到本地，重复帧、等待页、二维码页自动清理；
- OCR 把每页转成带 LaTeX 公式的 Markdown，并合成可翻页的课件 PDF；
- AI 按知识逻辑重组成**带页码引用的深度笔记**——要点旁标着页号，点一下跳到对应课件页；难点配讲解，习题给折叠答案；
- 复习台把笔记、课件、AI 对话放在同一屏：划词提问、间隔重复自测、知识链串联课程。

整理好的内容可以导出到安卓 App 离线复习。所有数据都在自己的设备上，不经过任何服务器。

名字取自「问渠那得清如许」——把杂乱的课件，理成一渠清水。

## 它适合谁

- 成都理工大学在校生，有问渠学堂账号，想系统整理录播课件（其他学校需自行修改学校配置）；
- 期末需要快速过课件、抓重点、自测的人；
- 习惯把资料收进 Obsidian / ima 的人——笔记就是标准 Markdown，并带课件 PDF 翻页链接。

## 快速开始

> 前置条件：Node.js 18+；Windows 需安装 Microsoft Edge（登录用，脚本自动定位）。「转 MD」另需一次性安装转换环境（约 6GB 模型，见下）。

桌面端四种启动方式（任选其一）：

| 方式 | Windows | macOS |
| --- | --- | --- |
| 网页版 | 双击 `start.cmd`（停止：`stop.cmd`） | 双击 `wqppt.command`（停止：`wqppt-stop.command`） |
| 桌面壳 | 双击 `启动复习软件.vbs` | 双击 `启动复习软件.command` |
| 命令行 | `npm install && npm start` → <http://127.0.0.1:3901> | 同左 |
| 升级 / 卸载 | `update.cmd` / `uninstall.cmd` | `bash wqppt.sh update` / `uninstall` |

第一次使用走完一遍：

1. **登录**：右上角「登录」，输入统一认证账号。动态防护需要真实浏览器会话，窗口默认在屏幕外，可在 设置 → 显示浏览器 唤出。
2. **下载**：勾选课程 → 「下载所选」；也可以点「课次」只下某一次课。
3. **清洗**：课程「批量清洗」。复核页里勾选＝清理、取消＝保留；被清理的帧进 `_回收站`，随时可恢复。
4. **转 MD**：课程「批量转 MD」。图片 → 带公式的 Markdown + 课件 PDF（需先装转换环境）。
5. **生成笔记 + 复习**：进入复习台点「生成笔记」，然后按「复习」队列做间隔重复自测。

### 安装转换环境（转 MD 用，一次性）

```powershell
# Windows（需 uv + Python 3.12；有 N 卡自动走 CUDA，否则 CPU）
powershell -ExecutionPolicy Bypass -File setup-p2t.ps1
```

```bash
# macOS / Linux（Apple 芯片自动走 MPS）
bash setup-p2t.sh
```

装好后课次旁才会出现可用的「转 MD」。也可以命令行直接转：

```bash
.venv-p2t/Scripts/python.exe ppt2md.py "downloads/课程/课次" --device auto   # Windows
.venv-p2t/bin/python ppt2md.py "downloads/课程/课次" --device auto           # macOS
```

## 📱 安卓 App

桌面端负责重活，App 负责随身复习。安装：[Releases](https://github.com/ADA-quart/cdut-wqxt-review/releases/latest) 下载 `qingqu-x.y.z.apk`；CI 自动构建、固定签名，新版本可直接覆盖安装。

**使用流程**

1. 电脑端「设置 → 导出」导出「内容包」（笔记 + 课件图；首次全量，之后可按课程 / 单课增量导出）；
2. 可选再导一个「学习记录包」（进度 + 标记 + 对话，几百 KB）；
3. 把 zip 传到平板 / 手机，App 内点「＋ 导入内容包」；
4. 之后完全离线使用。

**App 能做到**

- 笔记阅读（公式渲染、目录、页码角标、知识链）、课件翻页；
- 阅读进度自动记录，⭐ 重点 / ❓ 错题 / ✓ 掌握，复习队列（间隔重复），历史对话；
- 主题（跟随系统 / 浅色 / 深色 / 护眼暖纸）、正文字号四档、20-20-20 护眼提醒；
- 手机 / 平板的横屏竖屏均可：手机竖屏单列（笔记 → 课件 → 对话）、宽屏两栏。

**边界**：下载、转 MD、生成笔记、校订只在电脑端，App 内自动隐藏；内容存 App 私有存储，卸载即清；导入后的压缩包可以删除。

## 功能说明

以下按流水线顺序说明各环节，供使用时查阅。

### 下载（问渠学堂）

- 登录走学校统一认证，后台是独立 profile 的真实浏览器会话（动态防护必须如此）；
- 课程按学期筛选，可整课下载；课次弹窗里可预览图片、单独下载；
- **强制重新下载**（课件在服务器更新后用）：已有图片覆盖更新，已清洗的帧不拉回，服务器已删除的旧帧移入 `_回收站/_旧帧备份/`；
- 已存在且正常的图片自动跳过，重复下载幂等。

### 导入自定义课件

老师发的、自己找的课件也能进同一套流水线（转 MD → 清洗 → 生成笔记 → 复习）：已下载文件面板右上「＋ 导入课件」。

- **PPT / PPTX**：调用本机 PowerPoint 静默导出每页图；
- **PDF**：逐页渲染，可选 160 / 220 dpi（扫描件、图片拼合的 PDF 选高清）；
- **图片**：多选，按文件名顺序合成一节课。

### 清洗（去重）

- 规则：空白过渡帧丢弃；连续重复簇保留末帧；等待页与二维码页整段移除；
- 复核页把全部帧网格平铺：勾选＝清理（红框标出）、取消＝保留；勾选名单跨次沿用；
- 原始图片不删除，清洗只决定「转 MD 用哪些帧」；被清理的帧进 `_回收站`，随时拉回。

### 转 MD（课件数字化）

- Pix2Text 逐页 OCR 成 Markdown，公式保留 LaTeX；图形素材进 `<课次>_assets/`；
- 同时合成课件 PDF（图片合订），每页顶部带 `[[课次.pdf#page=N]]` 翻页链接，方便 Obsidian / ima 对照；
- 并行度按空闲显存与 CPU 核数自适应（V100 实测：模型基座 + 首页约 6.3GB，每多并行一页 +1GB，默认留 1.5GB 余量）。

### 校订（纠错 + 修公式）

- 一步跑完：OCR 错字逐页修正 → KaTeX 无法解析的公式按上下文修复，复验通过才写回；
- 备份 `.ocr-backup.md` / `.math-backup.md`；
- 三种模式：纯文本（省 token）/ 图片上云（视觉模型核对，精度最高）/ 图片本地（Ollama 等本机推理，零 API 费用）。

### 深度笔记（核心）

三遍加工，产出 `<课次>.note.md`：

1. **整理稿**：逐块消化 OCR 原文（按 mtime 缓存——原文没变时重跑直接复用，省 token）；
2. **成稿**：按知识逻辑重组小节（筛选 / 组织 / 关联 / 标注难点），要点带页码角标；难点配讲解；习题给折叠参考答案（先自己想再点开）；
3. **课末必记**：本课脉络与必记清单放笔记最前，并同步到原文 md 顶部的摘要块。

覆盖保证：每一页至少被引用一次；生成后自检修补遗漏页。

**笔记 PDF**：复习页「⋯ 更多 → 笔记 PDF」，无头 Edge 渲染 A4（公式渲染、习题全部展开），按 mtime 缓存秒开。

### 质量审计

三层检查：页覆盖（本地，不花钱）+ 忠实度逐条核对（LLM）+ 知识点清单（LLM）。发现与原文不符处自动修正（AI 自己的补充内容保留），改前备份 `.note-backup.md`，面板可对照修正前后。

### 复习台

- **布局**：左笔记（可切原文 md）、右上课件、右下 AI 对话；分隔条可拖动，布局按课次记忆；
- **笔记**：目录与小节折叠、四色荧光笔（核心考点 / 要背 / 已掌握 / 存疑）、页码角标点击跳课件；
- **课件**：翻页、缩略图、跟随滚动、键盘 ←→；⭐ 重点 / ❓ 错题 / ✓ 掌握 一键入队；🧠 出题生成问答卡；
- **AI 对话**：范围可选本课 / 本课程 / 全库（检索后回答并附来源）；划词「引用到提问 / 解释这段」；历史按课次保存；
- **复习队列**：间隔重复四档评分（再来一次 / 有点难 / 记住了 / 太简单）；费曼复述（AI 找缺漏）；导出 Markdown / CSV；
- **知识链**：课程内索引、课程间关联、反链、标签、图谱；
- **阅读舒适**：主题（跟随系统 / 浅色 / 深色 / 护眼暖纸）、正文字号四档、可选 20-20-20 护眼提醒。

### 导出 / 导入（与手机同步）

| 包 | 内容 | 用途 |
| --- | --- | --- |
| **内容包** | 笔记 + 原文 + 课件图 | 手机 / 平板；范围可选 全部 / 按课程 / 单课 |
| **学习记录包** | 阅读进度 + 复习卡 + 对话历史 | 双端来回合并 |
| **全量备份** | 全部内容 + 记录 | 备份 / 换机 |

- 包内带每课次**内容指纹**，App 端据此增量合并（新增 / 更新 / 跳过）；
- 导入合并规则：学习记录永远按时间合并（进度取新、卡片按 id、对话并集去重）；内容文件默认跳过、可勾选覆盖。

### 删除与回收站

课次可单选或批量多选删除。删除＝移入回收站，弹窗分两档勾选：课件与转换文件 / 学习记录（整理稿、对话、卡片**默认保留**）。设置 →「回收站」可恢复（原路返回）、彻底删除或一键清空。

## 数据与隐私

- 全部数据在本地：课件图、md、笔记、卡片、对话都在你的电脑上（默认 `downloads/`，可在设置中更改；笔记目录可以直接指向 Obsidian 库）；
- 没有账号系统、没有遥测、没有中转服务器。LLM 调用从本机直接发往你配置的服务商（OpenAI 兼容接口），key 存本地 `config.json`（已 gitignore）；
- 安卓 App 同理：内容存 App 私有存储，不上传。

## 常见问题

- **没有转换环境能做什么？** 登录、下载、清洗、导入现成 md 都能用；只有「转 MD」需要一次性安装（约 6GB 模型）。
- **为什么必须弹浏览器？** 问渠学堂登录与页面有动态防护（瑞数式 WAF），普通 HTTP 请求会被拦截；图片服务器无防护，可直下。
- **端口冲突？** 默认 3901，`PORT=xxxx npm start` 更换。
- **课件更新了怎么办？** 课次弹窗勾选「强制重新下载」→「重新转 MD」→「生成笔记」（缓存按 mtime 自动失效）。
- **数据会被改乱吗？** 原始 md 只在「校订 / 摘要块」两处写入且都有备份；笔记、审计、卡片、对话全部独立存储。
- **App 怎么更新 / 内容怎么同步？** 下载新 APK 覆盖安装；电脑重新导出后 App 导入，同一课次自动替换。
- **导入的 zip 能删吗？** 能，导入完成即入库，压缩包不再需要。

## 开发与构建

