### 应力分析复习笔记

#### 1. 应力张量与斜截面应力向量
- 弹性体内任意一点 $P$ 的应力状态可由应力张量 $[\tau_{ij}]$ 描述。
- 若已知该点法向单位向量为 $n = n_1 e_1 + n_2 e_2 + n_3 e_3$，则该法向对应面元上的应力向量 $t$ 可由柯西公式（Cauchy's formula）求得：
  $$t_i = \tau_{ij} n_j$$
  展开形式为：
  $$t_1 = \tau_{11}n_1 + \tau_{12}n_2 + \tau_{13}n_3$$
  $$t_2 = \tau_{21}n_1 + \tau_{22}n_2 + \tau_{23}n_3$$
  $$t_3 = \tau_{31}n_1 + \tau_{32}n_2 + \tau_{33}n_3$$
  [[2026-06-29第1-2节.pdf#page=2|2]] [[2026-06-29第1-2节.pdf#page=4|4]]
- 💭 讲解：这里利用了爱因斯坦求和约定。计算时，将应力张量矩阵的每一行分别与法向向量进行点乘，即可得到新的向量 $t$ 的三个分量。

#### 2. 正应力与剪应力
- **正应力** $\tau_n$：应力向量 $t$ 在法向 $n$ 方向上的投影。
  $$\tau_n = t \cdot n = t_i n_i$$
- **剪应力** $\tau_s$：应力向量 $t$ 在面元切向方向上的分量大小，可由总应力大小与正应力通过勾股定理求得：
  $$\tau_s = \sqrt{|t|^2 - \tau_n^2} = \sqrt{t_i t_i - \tau_n^2}$$
  [[2026-06-29第1-2节.pdf#page=4|4]] [[2026-06-29第1-2节.pdf#page=5|5]]

#### 3. 应力向量与法向的夹角
- 设应力向量 $t$ 与截面法向 $n$ 的夹角为 $\varphi$，则有：
  $$\cos \varphi = \frac{t \cdot n}{|t||n|}$$
- 由此可反推夹角 $\varphi = \arccos\left(\frac{t \cdot n}{|t||n|}\right)$。
  [[2026-06-29第1-2节.pdf#page=4|4]]
- 💭 讲解：在例题 4-1 中，求得的 $\cos \varphi = -0.5$，由此得出夹角 $\varphi = 120^\circ$。当 $\varphi > 90^\circ$ 时，说明正应力 $\tau_n$ 为负，即该面元受到的是压应力。

#### 4. 坐标变换与应力张量
- 当坐标系从 $ox_1x_2x_3$ 旋转到 $ox_1'x_2'x_3'$ 时，应力张量在新坐标系下的分量 $(\tau_{ij}')$ 可通过坐标变换系数 $\beta_{ij}$ 计算：
  $$\tau_{mn}' = \beta_{mi} \beta_{nj} \tau_{ij}$$
- 矩阵形式为：
  $$[\tau'] = [\beta][\tau][\beta]^T$$
  其中 $[\beta]$ 为坐标变换矩阵，$[\beta]^T$ 为其转置矩阵。
  [[2026-06-29第1-2节.pdf#page=6|6]]
- 💭 讲解：该变换公式适用于任何二阶张量。在计算时，通过矩阵乘法 $[\beta][\tau][\beta]^T$ 可以快速得到 9 个新分量，比逐项展开更直观高效。

- 已知理想弹性体的应变分量，通过广义胡克定律 $\tau_{ij} = \lambda \theta \delta_{ij} + 2\mu e_{ij}$ 求解应力分量，其中 $\theta = e_{11} + e_{22} + e_{33}$ 为体积应变。[[2026-06-29第1-2节.pdf#page=14|14]]
- 解题时先求 $\theta$，再代入各分量公式计算 $\tau_{11}, \tau_{22}, \tau_{33}$ 及切应力。[[2026-06-29第1-2节.pdf#page=14|14]]
- 💭 讲解：这里体现了“本构关系”的正向使用，材料常数 $\lambda$ 和 $\mu$ 被称为拉梅常数，这类问题考察对公式的熟练程度。[[2026-06-29第1-2节.pdf#page=14|14]]

### 广义胡克定律（应力求应变）

- 利用应力求应变的胡克定律公式 $e_{ij} = \frac{1}{E} [-\nu \Theta \delta_{ij} + (1 + \nu)\tau_{ij}]$，先求体积应力 $\Theta = \tau_{11} + \tau_{22} + \tau_{33}$。[[2026-06-29第1-2节.pdf#page=15|15]]
- 代入已知的弹性模量 $E$ 和泊松比 $\nu$ 以及应力分量，计算得到应变分量。[[2026-06-29第1-2节.pdf#page=15|15]]
- 💭 讲解：这道题考察了本构关系的反向使用。与上题不同，这里给出的是工程常数 $E, \nu$，需要区分拉梅常数与工程常数的转换关系。由于是考试，要求能熟练进行这两种不同表达式的代换。[[2026-06-29第1-2节.pdf#page=15|15]]

### 弹性柱体的轴向应力与应变比值

- 题目条件：各向同性线性弹性圆柱体，被置于光滑刚性圆筒内，受轴向均匀压力 $p$ 作用，横向变形完全受到限制，求轴向应力与轴向应变的比值。[[2026-06-29第1-2节.pdf#page=16|16]]
- 坐标系设定：$x_1$ 为轴向，$x_2, x_3$ 为横向。由于刚性圆筒限制，横向应变 $e_{22} = e_{33} = 0$，且横向应力 $\tau_{22} = \tau_{33}$。[[2026-06-29第1-2节.pdf#page=16|16]]
- 推导过程：根据 $e_{22}, e_{33}$ 的表达式，利用横向约束条件结合 $\Theta = \tau_{11} + 2\tau_{22}$，推导出 $\tau_{22}$ 与 $\tau_{11}$ 的关系，进而求得 $e_{11}$ 与 $\tau_{11}$ 的关系。[[2026-06-29第1-2节.pdf#page=16|16]]
- 最终结论：轴向应力与轴向应变的比值为 $\frac{\tau_{11}}{e_{11}} = \lambda + 2\mu$。[[2026-06-29第1-2节.pdf#page=16|16]]
- 💭 讲解：这是一个典型的“侧限压缩”问题。因为圆筒是刚性的，横向不能膨胀，所以 $e_{22} = 0$。这里求得的比值 $\lambda + 2\mu$ 是弹性波动力学中非常重要的参数，对应纵波模量。[[2026-06-29第1-2节.pdf#page=16|16]]
