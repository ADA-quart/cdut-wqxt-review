清渠 · 安卓端排版原型

手机端的核心矛盾：桌面端「笔记｜课件｜对话」三栏在 6 寸竖屏放不下。 方案是——竖屏收成三个整页（底部 Tab 切换），用「引用角标」把三页连起来； 横屏和平板则直接展开成双栏/三栏，和桌面端同一套界面按宽度自适应。 下面左屏可以真的点：点笔记里的蓝色角标试跳课件，点底栏切页。

竖屏手机：笔记 / 课件 / 问答 三整页 + 角标串联 横屏手机：左笔记右课件 平板：= 桌面三栏（右上课件、右下对话）

① 手机竖屏（可交互）

笔记页是默认页：阅读、勾选、点角标。课件页全屏看图（缩放/翻页/标记）。问答页管对话。

手机 / 平板保留什么

  • ✅ 笔记阅读（公式、角标、知识链、进度）
  • ✅ 课件看图：缩放、翻页、角标跳页、⭐/❓/✓ 标记
  • ✅ 引用提问 + LLM 对话（直连 API，含历史）
  • ✅ 复习队列（今日到期）、课次切换、全库搜索
  • ✂️ 不做：下载、OCR 转 MD、清洗去重、生成笔记、PDF/图谱

重活留在电脑端，手机只带「轻量数据包」进来（md + 图片 + 角标索引，就是现有「轻量导出」）。

三个页怎么互相串

  • 笔记里 12 角标 → 课件页直达第 12 页；课件页「📍跳回笔记」回到原段
  • 选中文字 → 浮条：引用提问 / 解释这段 / 复制；引用后自动跳问答页
  • 课件上的 ⭐❓✓ 与复习队列同源，和电脑端进度一致
  • 顶栏 ▾ 弹课次选择器；底栏三个 Tab 常驻，读到哪里都一键互跳

技术路线（复用桌面代码）

  • 同一套前端加响应式断点：<600dp 三 Tab、≥600dp 双栏、平板三栏——不另写一套 UI
  • Capacitor 套壳出 APK（和 ITDC 同一打法）
  • 数据层抽一个适配器：电脑走本地服务，手机读导入包（Filesystem/IndexedDB）
  • LLM 对话直连用户自己的 API（Key 存 Android Keystore），不经服务器
